Some BitStream Digital macOS packages may currently be distributed without Apple Developer ID notarization.

Because of this, macOS may display a security warning during installation or first launch.

If macOS blocks the application, review it under:

`System Settings → Privacy & Security`

Only approve an application if you downloaded it from an official BitStream Digital source.
